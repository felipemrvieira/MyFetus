# CHANGELOG

Registro das principais alterações realizadas no projeto MyFetus.

## [Unreleased]

### Documentação técnica v3

* Consolidado o guia de arquitetura, configuração local, API, segurança,
  testes, operação, limitações e transição para a próxima equipe.
* Adicionado o ER textual com entidades, relacionamentos, integridade e ordem
  executável das migrations.
* Registrado o ADR de uso de serviços externos com custo zero, créditos
  patrocinados ou recursos locais no ciclo acadêmico.
* Explicitado que o piloto usa dados sintéticos, que achados pós-freeze viram
  backlog/documentação e que a homologação não é produção.

## [2026.2]

### Sprint 0 — Planejamento

* Início do planejamento do ciclo 2026.2.
* Definição do planejamento e das metas do novo ciclo.
* Organização do backlog e das atividades do projeto.
* Definição do GitHub Projects como ferramenta para gerenciamento do backlog.
* Planejamento da disponibilização de um ambiente de homologação online com HTTPS.
* Identificação da necessidade de testes E2E para o aplicativo mobile.
* Criação da documentação de decisões arquiteturais por meio de ADRs.

### Sprint 1

* Continuação da organização e execução das atividades planejadas para o ciclo 2026.2.

## Histórico

### Ciclos anteriores

* O projeto anterior possuía execução predominantemente local.
* Não havia deploy de homologação/produção implementado.
* O aplicativo mobile não possuía testes E2E.
* O projeto não possuía `CHANGELOG.md` nem ADRs.
* Trello e Jira foram utilizados em ciclos anteriores para gerenciamento e acompanhamento das atividades.
